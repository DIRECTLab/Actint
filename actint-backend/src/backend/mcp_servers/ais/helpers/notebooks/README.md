## Notebooks
These were made as a proof of concept, however, they are mostly deprecated now. 

### What they do:
These do three main things
1. Get the direction the ships is going
2. The areas it is heading toward (North America, South America, Europe, straight of Hormuz, ect.) 
3. The ports it is going toward (like the panama canal)

The programs use a tool to calculate future position which account for the curvature of the earth and gracefully handle the poles.
